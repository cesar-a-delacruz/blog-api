# Blog API

![screenshot](./public/screenshot.png)

## Overview

This project is a blog in which you can see publicposts and their comments. To access you need to register either as an author or reader and depending on the role you choose you can create your own posts or comment on other posts.

**[Check it here](https://a-link.com/)**

## Main Features

1. Account handling (registration, login, profile view, data update and deletion)
2. Post submission (as an author) with title, description, image and state (public or private)
3. Comment submission (as a reader)
4. Editing and removal of both posts and comments
